# Terminator

An Omarchy theme with a dark steel-blue palette, crimson accents, and eight dystopian-machine wallpapers.

## Install

```sh
omarchy theme install https://github.com/benwillems/omarchy-terminator-theme.git
```

Or copy this folder to `~/.config/omarchy/themes/terminator` and run:

```sh
omarchy theme set terminator
```

Cycle backgrounds with `omarchy theme bg next` or the Omarchy wallpaper picker.

## Remove

```sh
omarchy theme set "Tokyo Night"
rm -rf ~/.config/omarchy/themes/terminator
```
